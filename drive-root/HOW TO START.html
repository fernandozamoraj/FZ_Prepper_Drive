How to start the Prepper Kit

Encyclopedia, medical help, survival guides, the Bible, maps and driving directions. No internet needed.

🪟 Windows computer

  1. Plug in the drive. Open it: click File Explorer (the folder icon), then the drive named PKNY_256 on the left.
  2. Double-click Start Prepper Kit (Windows).
    (It may show as Start Prepper Kit (Windows).bat.)
  3. A black window opens. Leave it open. After a few seconds your web browser opens the Home page.
  4. When you're done: close the black window (the ✕ in its corner).
The first time only, Windows may ask “Windows Defender Firewall has blocked some features…”. Click Allow access so phones on your Wi-Fi can use it too. (Clicking Cancel is also fine: it then works only on this computer.)

If you see “Windows protected your PC”, click More info, then Run anyway.

🍎 Mac computer

  1. Plug in the drive. It appears on the desktop (or in Finder on the left) as PKNY_256. Open it.
  2. Double-click Start Prepper Kit (Mac).
  3. A Terminal window opens with text in it. Leave it open. After a few seconds your web browser opens the Home page.
  4. When you're done: close the Terminal window. If it asks “Do you want to terminate running processes?”, click Terminate.
The first time only, the Mac may ask:
• “Terminal would like to access files on a removable volume”: click Allow.
• “Do you want the application to accept incoming network connections?”: click Allow.

If it says the file “cannot be opened because it is from an unidentified developer”: right-click (or Control-click) the file, choose Open, then click Open.

What's inside

⌂ HomeOne search box for everything.
📚 LibraryWikipedia, medical, survival, repair, cooking, gardening, ham radio, travel.
📖 BibleKing James Version. Type John 3:16 or any words.
🗺️ MapsWhole US map with driving directions. Press Directions.

The bar at the top of every page has a ⌂ Home button to get back.

If the browser doesn't open by itself

Open your web browser (Chrome, Edge, Safari or Firefox) and type this in the address bar at the top:

localhost:8000

Using it on a phone or tablet

The computer and the phone must be on the same Wi-Fi (no internet is needed, just the Wi-Fi router turned on). The black/Terminal window shows the address to type on the phone, for example http://192.168.1.20:8000.

If something goes wrong

  • “The kit already seems to be running”: it's already open. Look for the other black/Terminal window, or just use the browser page.
  • Directions don't work right away: wait 10 seconds and try again; the directions part starts last.
  • Nothing happens at all: unplug the drive, plug it back in, and try again. Keep the launcher file next to the offline-prepper-kit folder; don't move it out of the drive.
