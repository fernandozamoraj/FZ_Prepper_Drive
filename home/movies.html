Tips

  • Phones and TVs: any device on the same Wi-Fi can watch at once. On a phone, turn it sideways and use the player's full-screen button. AirPlay / Chromecast from the player work when the TV is on the same network.
  • This device remembers where you stopped each film.
  • Add a video copies it into the kit's movies/ folder, so it goes along when the kit is copied to a thumb drive. Anyone on the Wi-Fi can add; only the computer that runs the kit can remove (removed videos go to movies/.trash). For a big collection already on a drive, add its folder on the Settings page instead (nothing is copied).
  • A file that won't play in the browser (some .mkv or .avi you added) can still be downloaded and played with VLC or mpv from the Software page.
