Add folders of your own movies, books and audiobooks: a folder on this computer, a USB drive or the kit's thumb drive. They show up on the Movies and Books pages for every device on the Wi-Fi. Nothing is copied: the files are played and read where they are.

Good to know

  • The folders are saved in kit-settings.json in the kit folder and looked through every time the kit starts. Added or removed files since then? Press Look again.
  • Movies: every video file in the folder and the folders inside it (.mp4, .m4v, .webm, .mkv, .avi, .mov). MP4 plays on every phone; other files may need VLC from the Software page.
  • Books: EPUB, PDF, MOBI, AZW3, TXT and other book files. Audiobooks: a folder of MP3 / M4B / M4A files is one audiobook, played in order; a single .m4b file is one too.
  • A folder on the kit's own thumb drive is remembered relative to the kit, so it is still found when Windows gives the drive a different letter. A folder on a drive that isn't plugged in stays in the list as “not found”.
  • Only the computer that runs the kit can change these folders. Phones and other devices can see the list.
