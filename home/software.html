Installing without internet

  • Windows: run the .exe or .msi. If Windows says it "protected your PC", click More info → Run anyway. A .zip opens in File Explorer; a .7z needs 7-Zip (install it first).
  • Mac: open the .dmg and drag the app to Applications. If macOS won't open it, right-click the app → Open → Open. Pick Apple Silicon (M1 and later) or Intel where there are two ( → About This Mac shows which).
  • Linux: make an .AppImage runnable (chmod +x Thorium*.AppImage) and double-click it; sudo apt install ./file.deb for a .deb; unpack .tar.xz with tar -xf.
  • Only official releases, straight from each project (GitHub, VideoLAN, Mozilla, libretro, the SumatraPDF site): no download portals, so no bundled adware. ✓ verified means the file matched the publisher's own checksum; SumatraPDF and RetroArch publish none, so those come from their official HTTPS sites unchecked.
